# Examples — Neo4j

This directory will contain Python scripts using the official `neo4j` Python driver for all demonstrations.

## Planned Example Scripts

| File | Description |
|------|-------------|
| `00_connection.py` | Connect to a local Neo4j instance using the Bolt protocol |
| `01_seed_graph.py` | Create all User and Post nodes and all relationships |
| `02_follower_queries.py` | Run and display direct follower, following, and mutual queries |
| `03_friends_of_friends.py` | Execute 2-hop traversal and display suggested users |
| `04_shortest_path.py` | Find and display the shortest path between two users |
| `05_pagerank.py` | Execute GDS PageRank and display top influencers |
| `06_graph_visualisation.py` | Export graph data for visualisation in Neo4j Browser |

## Prerequisites (Not Yet Installed)

- Neo4j Desktop or Neo4j Community Server (local)
- Neo4j Graph Data Science (GDS) plugin (for PageRank)
- Python package: `neo4j`
