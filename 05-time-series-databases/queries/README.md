# Queries — InfluxDB

This directory will contain Flux query files for all InfluxDB demonstrations.

## Planned Query Files

| File | Description |
|------|-------------|
| `01_likes_per_minute.flux` | Likes per minute for a specific post over a 24-hour window |
| `02_trending_posts.flux` | Top 5 posts by like count in the last hour |
| `03_event_type_totals.flux` | Total events per type (like, view, comment, share) in last 7 days |
| `04_user_activity_heatmap.flux` | Event counts grouped by hour-of-day for activity pattern analysis |
| `05_engagement_rate.flux` | Ratio of active users to total events per time window |
| `06_anomaly_detection.flux` | Spike detection — events exceeding 2x the rolling average |
| `07_downsampling_task.flux` | Scheduled Flux task to aggregate minute data into hourly summaries |
