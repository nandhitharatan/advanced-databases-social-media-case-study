# Queries — Firebase Firestore

This directory will contain Python SDK query examples for all Firestore demonstrations.

## Planned Query Files

| File | Description |
|------|-------------|
| `01_basic_read_write.py` | CRUD operations on the `users` collection |
| `02_subcollection_query.py` | Fetch all comments from `/posts/{id}/comments` |
| `03_composite_index_query.py` | Query posts filtered by tag + sorted by `created_at` |
| `04_array_contains_query.py` | Query posts containing a specific tag in the `tags` array |
| `05_pagination_query.py` | Paginated post feed using `start_after()` cursor |
| `06_collection_group_query.py` | Query all comments across all posts using collection group |
