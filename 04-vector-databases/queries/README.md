# Queries — ChromaDB

This directory will contain Python query scripts for all ChromaDB demonstrations.

## Planned Query Files

| File | Description |
|------|-------------|
| `01_semantic_search.py` | Search the post collection using a natural language query |
| `02_metadata_filtered_search.py` | Semantic search filtered by tag metadata |
| `03_content_recommendation.py` | Given a liked post, find K most similar posts |
| `04_similarity_comparison.py` | Compute and display cosine similarity between selected post pairs |
| `05_distance_metrics.py` | Compare query results using cosine vs. L2 (Euclidean) distance |
